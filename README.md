# llm-learning-rocm

个人大模型技术学习与实验仓库，用于入门学习大模型推理、量化及ROCm生态适配。

## 当前进展
- ✅ 完成CPU环境下小模型推理测试
- ✅ 完成transformers基础用法学习笔记
- ✅ 编写ROCm环境推理脚本（待验证）
- ⏳ 待GPU算力支持后开展更大模型实验

## 环境要求
- Python 3.9+
- PyTorch 2.0+
- Transformers 4.35+
- ROCm 6.0+（GPU环境）
